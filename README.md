UnicodeSlideshow
===

Current version: Unicode 17.0

An attempt to display all the assigned Unicode characters and emoji with useful information, when available:
- code point(s)
- block
- canonical name
- alias name

And for kanji:
- Mandarin
- Japanese
- Vietnamee
- Hangul
- Definition

CSS stack:
- Windows system fonts
- Aegyptus + UnicodiaSesh
- Google Noto fonts
- Unifont
