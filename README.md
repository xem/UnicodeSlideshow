UnicodeSlideshow
===

Demos:
- https://xem.github.io/UnicodeSlideshow/unicode.html (unicode + emoji slideshow)

Data:
- https://xem.github.io/UnicodeSlideshow/data/index.html (full tables)
- https://xem.github.io/UnicodeSlideshow/data/chars.html (just the glyphs, js script)
- https://xem.github.io/UnicodeSlideshow/data/chars.static.html (just the glyphs, static)
- https://xem.github.io/UnicodeSlideshow/data/tsv.html (full tsv, js script)
- https://xem.github.io/UnicodeSlideshow/data/tsv.tsv (full tsv, static)

Current version:
- Unicode 17.0

This project aims to display all the assigned Unicode characters and emoji with useful information, when available:
- code point(s)
- block
- canonical name
- alias name

And for kanji:
- Mandarin
- Japanese
- Vietnamee
- Hangul
- Definition

CSS stack:
- Windows 11 system fonts
- Specific fonts found online (checked / fixed by me)
- Google Noto fonts
- GNU Unifont

Best viewing conditions:
- Windows 11
- Firefox
- install all the fonts from the /font/ folder as system fonts

Possible future improvements:
- Extract vector graphics from unicode specs for blocks with no font available (or Unifont only).
- Use these graphics in the demos
- Credit Unicode's copyright + educational use
